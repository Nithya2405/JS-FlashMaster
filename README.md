This is a solution to the [Flashcard App project](https://roadmap.sh/projects/flash-cards) from roadmap.sh.

A simple **JavaScript flashcard learning app** built with **React + Vite**.
It helps developers review key JavaScript concepts using **interactive flip cards** and **progress tracking**.

🔗 **Live Demo:**

## ✨ Features

* Interactive **flip flashcards**
* **Next / Previous navigation**
* **Progress bar tracking**
* **Reset learning session**
* Smooth UI animations

---

## 🛠 Tech Stack

* React
* Vite
* TypeScript
* TailwindCSS
* Motion (animations)
* Lucide React (icons)

---

## ⚙️ Installation

```bash
git clone https://github.com/Nithya2405/JS-FlashMaster.git
cd JS-FlashMaster
npm install
npm run dev
```

App runs at:

```
http://localhost:3000
```
